# 数据集管理

各功能页（标注、训练、分割、根系表型）共享同一个「当前数据集」。数据集统一存放在软件目录下，导入时复制文件，原始目录不受影响。

## 存储结构

```
workspace/datasets/
├── .state.json                 # 当前选中的数据集
├── .cache/                     # 临时文件（根系分析按类别导出的掩码、分割中间结果），可删除
└── <数据集 ID>/                # 如 ds-20261017-153000-a1b2，创建后不变
    ├── dataset.json            # 名称、分割类型、类别定义、像素值映射、来源与操作记录、格式版本
    ├── samples.json            # 样本：原图与掩码的显式对应关系、状态、尺寸、来源文件
    ├── images/                 # 未划分样本的原图（主名在整个数据集内唯一：a.png 与 a.jpg 不会共存）
    ├── masks/                  # 未划分样本的掩码
    ├── train/                  # 训练集（可选）
    │   ├── images/
    │   └── masks/
    ├── val/                    # 验证集（可选），结构同上
    ├── test/                   # 测试集（可选），结构同上
    └── reports/                # 导入、校验、转换、配对等报告（JSON）
```

- 数据集 ID 固定，重命名只改显示名称，不影响文件关联。
- 数据集可以完全不划分（只有 `images/`、`masks/`），也可以全部或部分样本划分到 `train/`、`val/`、`test/`；`samples.json` 中每个样本的 `split` 字段与其所在目录一致。
- `samples.json` 中的路径都相对数据集目录，整个目录拷贝到其他位置或其他电脑后仍可读取。
- 可用环境变量 `PLANT_PHENOTYPE_WORKSPACE` 改变 `workspace` 位置。

## 掩码约定

| 分割类型 | 存储 | 说明 |
|---|---|---|
| 语义分割 | `[<划分>/]masks/<主名>.png`，每张原图一张类别编号图 | 像素值即类别 ID：0=背景、1=根、2=叶……超过 255 类时用 16 位 PNG |
| 实例分割 | `[<划分>/]masks/<主名>/inst_001.png …`，每个对象一张 0/255 二值图 | `samples.json` 记录实例 ID 与类别 ID，实例之间允许重叠 |

- 掩码只用无损 PNG；显示颜色存于类别定义，与标签值分开，改颜色不改像素。
- 导入时通过「像素值映射」把外部掩码转换为类别编号：灰度值记为 `"255"`，颜色记为 `"#rrggbb"`。存在未映射值的掩码不写入，记入失败报告。
- 样本状态：未标注 / 已标注 / 预测（候选）。预测结果默认不参与训练。

## 保护规则

当前标注工具和训练加载器只支持二值（背景 + 一个前景类别）。为避免多类别和实例数据被二值化覆盖：

- 多类别语义或实例数据集在标注页只读显示（各类别合并为前景），保存会被拒绝；已有掩码含未定义标签时，二值保存也会被拒绝。
- 训练前会检查数据集，多类别或实例数据集直接报错，提示先在「标签」中合并类别（建议先复制数据集）。
- 分割结果写回只填充未标注/预测样本，人工标注不会被覆盖；多类别数据集只能「另存为新数据集」。
- 根系表型对多类别/实例数据集按所选类别导出二值掩码到 `.cache` 再分析，不改动原数据。

## 数据划分（train / val / test）

- **导入时保留**：源目录路径中出现 `train`/`training`、`val`/`valid`/`validation`、`test`/`testing` 目录时识别为划分，支持 `train/images` + `train/masks`、`images/train` + `masks/train`、`train/a.png` + `train/a_mask.png` 等组织方式。扫描结果会列出各划分的原图数，默认勾选「保留源目录中的 train / val / test 划分」。不同划分中的同名文件分别配对各自目录下的掩码，导入后加划分前缀（如 `train_a.png`）保证主名唯一。
- **设置划分**：在样本列表中多选样本，移到训练集 / 验证集 / 测试集或移回未划分；原图和掩码随之移动到对应子目录。
- **随机划分**：按比例（默认 70/20/10）和随机种子划分，可选全部样本、仅未划分样本或仅选中样本；按样本状态分层抽样，使各子集的已标注比例接近，样本很少时保证每个比例大于 0 的子集至少一个样本。
- **训练**：数据集有验证集时，训练集与未划分样本用于训练、验证集用于验证；没有验证集时按 `train_val_split` 从训练样本中随机划出；测试集始终不参与训练。自定义数据目录下存在 `train/`（及 `val/`）子目录时同样按子目录训练与验证。
- **其它功能**：导出默认保留划分（`<导出目录>/train/images` 等），再导入时可还原；转换生成的新数据集、分割结果「另存为新数据集」沿用源样本的划分；校验会提示划分与文件所在目录不符的样本。

## 功能

- **数据集**：新建、导入（同目录 `*_mask.png`、`images/` + `masks/` 分目录，可再按 train/val/test 组织；掩码可为二值、类别编号或彩色）、切换、重命名、复制、删除；检测到数据集根目录下的旧数据目录时可一键导入。
- **样本与配对**：自动配对，手动指定/解除掩码，按命名规则从外部目录批量配对（先预览），标记状态，设置/随机划分 train/val/test。
- **标签**：重命名、改颜色、添加、删除（仅未使用的类别）、编辑像素值映射；合并类别前预览受影响的样本数与像素数。
- **校验**：缺失文件、重复配对、尺寸不一致、未知标签、有损格式掩码、状态与掩码不符、划分与目录不符、未登记文件；双击问题定位到样本。
- **转换与导出**：实例 → 语义（丢失个体区分）、语义 → 实例（连通域拆分，结果标为候选）；转换生成新数据集并保留源数据和转换记录。导出为同目录或分目录布局，掩码可选类别编号、彩色或 0/255。

尚未支持：多类别标注、实例训练、COCO 格式导入导出；切块与还原仍按文件夹操作。

## 代码位置

- `plant_phenotype/datasets/`：纯 Python 数据层（不依赖 Qt），可在后台任务中使用。`store.py` 存储与标签操作，`pairing.py` 配对规则，`importer.py` 导入/批量配对/分割结果入库，`validation.py` 校验，`convert.py` 转换导出，`training_source.py` 训练读取入口。
- `plant_phenotype/app/dataset_service.py`：当前数据集服务，变化时通知各页面。
- `plant_phenotype/app/plugins/datasets/`：「数据集」页与 `datasets.*` 后台工具。
- `plant_phenotype/gui/dataset_panel.py`：各功能页右侧共用的数据集样本面板。
