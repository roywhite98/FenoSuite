# 根系表型beta

这是独立标签页，使用带直径的矢量折线表示每条根，并保存根之间的父子关系。原有「根系表型」页继续提供骨架图分析。

## 一次完整分析

1. **选择掩码**：载入二值分割结果，背景为 0、根为非零值。建议使用 PNG/TIFF 等无损格式；JPEG 的背景压缩噪点也可能被当作前景。可选同尺寸的原图作为底图。
2. **点选待分析根系**：在根内任意位置单击，基部、中段、主根尖或侧根尖都可以。同一连通根系重复选点只解析一次；可点选多株独立根系。不选点或点击背景时不会分析整张图。
3. **开始解析**：只从选中连通域向外连接方向相向、距离合适的断口，过滤孤立噪点、填补小孔洞并去除骨架短毛刺。随后压缩为矢量根段，先根据完整路径的长度、粗细和走向连续性判断主根，再识别侧根及父子关系。界面支持取消；切换图像或修改文档后，旧任务不能覆盖新状态。
4. **检查根树**：主根级次为 0，直接侧根为 1，侧根的侧根为 2。主根为红色、一级侧根为蓝色、更高级侧根为紫色、未归属段为灰色；待确认的根使用虚线，颜色仍表示候选级次。编号和级次在右侧根树中查看，画布不再显示根名称和级次文字。PNG、SVG 使用相同的级次配色。
5. **校正交汇**：选中画布标记或右侧交汇列表，查看端口编号与候选配对。选择分叉、穿越、接续或停止；点击「确认该解释」应用，也可选择「暂不确定」。X 型穿越不会自动创建父子关系。
6. **保存结果**：JSON 保存完整矢量文档；表格与图像是从该文档派生的导出结果。

点击只确定分析范围，不指定生长方向。基部由主根两端附近的粗细自动推断；粗细相近时以上方、再左方端点为基部，可用「反向」校正。自动推断和人工确认分别记录。旧版基部标记文档仍可打开；重新解析时将其标记作为范围选点。

若两个端点附近的根径相近，而且明显粗于其余端点，自动主根路径优先连接这两个粗端，以免断根后的细侧根绕路把真正主干排除。单个最粗端可能来自断口或膨大的交汇，不能独自决定起点；没有明显成对证据时仍比较完整端点路径。若路径在两段粗根之间经过较长细根，该主根及依赖它的侧根归属标为待确认并显示虚线，诊断提示可能绕过主干断口；人工明确确认的根保留确认状态。检测在重新接续时重算，不表示缺失主干已恢复。`combo_012` 就含有这类绕路和超出默认补接范围的缺口。CSV/XLSX 的 `quality_flags` 列记录绕行与主根归属不确定的原因；长度仍是当前候选折线的长度，不能当作恢复后的真实主根长度。

主根判断综合完整路径的长度、粗细和局部方向连续性，增强粗根的评分权重，避免长细侧根轻易胜出。单个分叉处更直的接续不会直接否决整条弯曲主根；闭环候选路径同时考虑长度与粗细，减少走入细根捷径的情况。交汇惩罚只影响附近根段，避免密集侧根对共享长主干重复扣分。复杂粘连、缺失及主侧根粗细接近时仍需核对。旧结果需点击「开始解析」重新计算；仅打开已保存文档会保留原有结果。

「断根连接上限」默认 20 px，只连接方向相向的端点，且桥线不能穿过第三个连通域；设为 0 可关闭。「去毛刺长度」默认 5 px，删除不超过该长度的末端短枝，设为 0 保留全部细侧根。断口过大、弯曲或分割缺失严重时不会强行连接；真实短侧根也可能符合毛刺条件，应按图像分辨率调整参数。补接像素处的直径标为缺失，不伪装成实测直径。

## 编辑与导航

- 滚轮缩放，右键或中键平移，「适应画面」恢复全图。
- 「选择根」模式下点击折线；交叉处重复点击可切换重叠根。
- 「编辑节点」模式下选根并拖动节点；节点移动后原有直径测量失效，可人工设置直径。
- 子根首点受父根附着点约束。移动父根附着点时，子根首点同步移动；如需换位置，选择新的父根和附着节点后「更新附着」。
- 「解除附着」让根变为待归属对象；不会自动把它改为主根。「反向」用于无父根对象，已附着子根需要先解除附着。
- 「删除根」保留其子根为待归属对象。误删或错误编辑可撤销；撤销、重做也会取消过期后台任务。
- 人工修改节点与附着关系受保护。若新的接续方案无法映射这些编辑，系统报冲突并保留当前文档；可撤销相关编辑后重新选择接续。

## 测量与导出

长度来自保存的折线；平均直径按有效区间长度加权，交汇处缺失或插值的直径不混入实测均值，并输出有效直径覆盖率。根数按具有确定级次的独立根对象统计，未归属片段单列。

默认单位为 px。输入「mm/px」并「应用标定」后，导出同时保留像素列和物理单位列。被图像边缘截断的根只具有可见长度，停止于待定交汇的根只具有已解析长度。

| 格式 | 内容 |
| --- | --- |
| JSON | 几何、节点直径、范围选点、自动基部、父子附着、交汇决定、分析快照及来源信息，可重新打开继续工作 |
| CSV | 每条根一行的根测量表；需要节点、附着与汇总明细时使用 XLSX |
| XLSX | roots、nodes、attachments、summary 四个工作表 |
| SVG | 可缩放的矢量根图 |
| PNG | 全图范围的当前矢量叠加图 |

JSON 重开时会检查源掩码是否仍匹配。源文件缺失或内容改变时，已有矢量仍可显示、编辑和导出，但旧分析快照不能继续自动接续；需要重新分析新掩码。

## 当前边界

该版本针对二维分割掩码，不重建被遮挡的真实三维根系。分析范围是用户选中的连通根系及满足断口条件的邻接碎片；两株根已经粘连时，单靠连通域不能可靠区分植株，需要校正交汇或先修改掩码。选中根系内的分叉默认按同株主侧根解析，真实穿越可通过「校正交汇」改为穿越。闭环保留待确认。主根和基部均为形态学推断，不能替代植物发育来源判断。直径采用距离变换估计，未实现灰度亚像素边界精修。
