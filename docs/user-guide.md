## 1. 简介与功能概览

### 1.1 软件定位

plant_phenotype 用于植物（尤其是根系）图像的**标注 → 训练分割模型 → 批量分割 → 表型分析**全流程，无需依赖仓库外的其他工具目录。

### 1.2 四大功能模块（四个 Tab）

| Tab         | 功能说明 |
|------------|----------|
| **数据标注** | 选择工作目录，用笔刷/橡皮/油漆桶标注前景，保存为 `*_mask.png`；支持对目录执行切块、从切块还原整图；有对应 mask 时自动叠加显示。 |
| **模型训练** | 使用标注好的数据训练分割模型；支持**本地训练**（本机 GPU/CPU）、**SSH 远程**（服务器无需部署项目）或 **HTTP 服务**（数据打包提交到远程训练服务）；可预览/编辑 YAML、从已有 checkpoint 继续训练。 |
| **图像分割** | 选择权重与配置文件，对单张图像预览或对目录批量分割，结果写入输出目录的 `masks/`；支持预览/编辑 YAML。 |
| **根系表型** | 加载掩码图，预处理后在图上点选根、校正主根、进行拓扑与表型统计，导出 CSV/Excel 与可视化图。 |

### 1.3 典型工作流

1. **数据标注**：在工作目录中打开原图 → 用笔刷/橡皮/油漆桶标注根系区域 → 保存为 `xxx_mask.png`；可选「对目录执行切块」得到训练用切块。
2. **模型训练**：设置数据目录、选择/编辑 YAML 配置 → 本地或远程「开始训练」→ 得到 `best_model.pth` 等。
3. **图像分割**：选择权重与配置、图像目录与输出目录 → 「开始分割」→ 在输出目录的 `masks/` 下得到预测 mask。
4. **根系表型**：选择掩码图 → 「预处理」→ 在图上点击根所在位置（可多选）→ 可选「校正主根」→ 导出 CSV/Excel/可视化图。

## 2. 安装与运行

### 2.1 环境要求

- **Python**：建议 3.10、3.11 或 3.12（3.14 下部分依赖可能需从源码编译）。
- **操作系统**：Windows / Linux / macOS。
- **GPU**（可选）：训练与分割建议使用 NVIDIA GPU + CUDA；仅标注与根系表型可只用 CPU。

### 2.2 安装依赖

在**仓库根目录**执行：

```bash
pip install -r requirements.txt
```

- 使用 **DINOv3** 模型时，额外执行：`pip install -r requirements-dinov3.txt`（根目录）。
- SSH 远程训练需要 `paramiko`，HTTP 训练服务端需要 `flask>=2.0.0`，二者均已包含在 requirements.txt 中。

也可使用 Conda：根目录提供 `environment.yml`，可据此创建环境后再安装上述依赖。

### 2.3 启动 GUI

**推荐：在仓库根目录执行**

```bash
python run.py
```

或先安装包再从任意位置运行：

```bash
pip install -e .
python -m plant_phenotype.main
```

启动后出现主窗口，包含数据集、数据标注、模型训练、图像分割、根系表型和根系表型beta 六个 Tab。

### 2.4 其他入口

- **远程训练服务**（见第 7 节）：在仓库根目录执行 `python run_server.py`，默认监听 `http://0.0.0.0:8765`。
- **CUDA 诊断**：`python scripts/check_cuda.py`，用于检查 PyTorch 是否支持 GPU 及安装建议。
- **依赖安装辅助**：`python scripts/install_requirements.py`，会读取根目录的 `requirements.txt` 并执行安装（Python 3.14 时会提示版本建议）。

## 3. 数据标注

### 3.1 界面布局

- **左侧**：画布（显示原图与标注层）、底部状态栏。
- **右侧**：工作目录树，可展开文件夹并点击图像文件名打开图像。
- **顶部工具栏**：打开图像、保存 Mask、选择标注目录、切块/还原、笔刷形状与大小、橡皮/油漆桶、标注透明度、显示标注层。

### 3.2 基本操作

1. **选择工作目录**：点击右侧「选择工作目录」，选择原图所在文件夹；上次选择的目录会被记住。
2. **打开图像**：在右侧树中点击某张图像，或点击工具栏「打开图像」选择文件。支持的扩展名：`.png`、`.jpg`、`.jpeg`、`.bmp`、`.tiff`、`.tif`、`.webp`。
3. **标注**：
   - **笔刷**：圆形/方形可选，大小 1–200 可调；在画布上按住鼠标左键涂抹即为前景。
   - **橡皮**：勾选「橡皮」后涂抹会擦除前景。
   - **油漆桶**：勾选「油漆桶」后点击画布，对连通区域填充前景。
   - **标注透明度**：滑动条调节标注层叠加透明度（10%–100%）。
   - **显示标注层**：勾选/取消可显示或隐藏标注叠加。
4. **保存 Mask**：点击「保存 Mask」或使用快捷键 **Ctrl+S**。若已设置「选择标注目录」，则保存到该目录下的 `xxx_mask.png`；否则会弹出保存路径对话框。Mask 为二值图（前景 255，背景 0）。
5. **撤销**：**Ctrl+Z** 撤销上一次笔刷/橡皮/油漆桶操作。

### 3.3 与已有 Mask 的配合

- 若当前图像**同目录**或**标注输出目录**下存在同名 `xxx_mask.png`，打开图像时会自动加载并叠加显示，可在此基础上继续编辑。
- 切换图像时若有未保存的标注，会提示是否保存；可勾选「下次默认保存（切换图片时自动保存，不再询问；重启软件后重置）」。

### 3.4 快捷键

- **Ctrl+S**：保存 Mask。
- **Ctrl+Z**：撤销。
- **← / →**：在同级目录内切换上一张/下一张图片（仅限当前图像所在文件夹内的图像列表）。
- **Ctrl + 滚轮**：调整笔刷大小（在画布上）。

### 3.5 对目录执行切块

用于将大图（及可选已有 mask）切成固定大小块，便于训练或减少单张显存占用。

1. 点击「对目录执行切块」。
2. **选择要切块的目录**：原图所在目录，该目录下可有或没有 `*_mask.png`。
3. **选择切块输出根目录**：切块图像与 meta 将写入该目录下的子目录（按源目录名或默认命名）。
4. 在对话框中设置：
   - **切块大小（像素）**：如 512，范围 64–2048。
   - **前景比例阈值**：若某块在 mask 中前景像素占比低于该值，该块会被标记为排除（不参与训练等）；无 mask 时仍会切块，mask 全黑并记入 excluded。
5. 确认后执行，完成后提示已处理张数及输出路径。

支持格式与「打开图像」相同（.png、.jpg 等）。有 mask 时按前景比例过滤；无 mask 时直接按块切割原图。

### 3.6 还原切块为整图

从之前切块得到的、**含有 meta.json** 的子目录，将切块拼回整图与整 mask。

1. 点击「还原切块为整图」。
2. 选择**切块目录**（内含 `meta.json`）。
3. 选择**保存路径**（整图 PNG 路径）；程序会自动在同一目录下生成 `xxx_mask.png`（整 mask）。

## 4. 模型训练

### 4.1 训练方式

- **本地训练**：在本机进程内执行，需要本机具备 GPU（或勾选「仅使用 CPU」）。日志实时显示在下方文本框。
- **SSH 远程**（推荐用于云 GPU）：通过 SSH 把最小训练代码、数据与配置上传到服务器，在服务器后台训练，日志实时回传，结束后产物自动下载到本地「保存目录」。服务器只需装好 PyTorch 的 Python 环境，**无需部署项目、无需开放额外端口**。
- **HTTP 服务**：将配置文件与数据目录打包上传到远程地址；本机仅提交任务并轮询日志。远程机器需先运行 `python run_server.py`（见第 7 节）。

在「训练方式」下拉框中选择「本地训练」「SSH 远程」或「HTTP 服务」。

### 4.2 路径与参数

| 项           | 说明 |
|--------------|------|
| **配置文件** | YAML 路径，如 `resources/configs/unet.yaml`。可「浏览...」选择，可「预览 YAML」在弹窗中查看/编辑并保存。 |
| **数据目录** | 包含训练/验证图像的根目录；界面会将该路径传给训练逻辑（覆盖或补充 YAML 中的 `data.root_dir`）。图像与 mask 可同目录按命名区分（`xxx.png` / `xxx_mask.png`），或使用子目录 `images/`、`masks/`（在 YAML 中配置 `images_dir`、`masks_dir`）。 |
| **保存目录** | 本地训练与 SSH 远程时有效（SSH 远程训练结束后产物下载到这里）；训练产物（best_model.pth、曲线、日志等）写入该目录；不填则使用配置文件中的 `train.save_dir`（如 `./workspace/runs/training`）。 |
| **继续训练权重** | 可选；选择已有 `.pth` 文件，从该权重继续训练（含优化器/轮次时一并恢复）。 |
| **仅使用 CPU** | 仅对「本地训练」有效；勾选后强制使用 CPU，不占用 GPU。 |

### 4.3 操作步骤（本地）

1. 选择「本地训练」。
2. 选择或填写配置文件路径；需要时点击「预览 YAML」修改并保存。
3. 选择数据目录（必须包含图像与 mask，结构符合 YAML 或默认约定）。
4. 可选：选择保存目录、继续训练权重；按需勾选「仅使用 CPU」。
5. 点击「开始训练」；下方日志框会实时输出训练日志。训练结束后「开始训练」按钮重新可用。

### 4.4 操作步骤（SSH 远程）

1. 选择「SSH 远程」，在「SSH 服务器」区域填写：
   - **连接**：可直接粘贴云平台给出的登录指令，如 `ssh -p 2222 root@192.168.1.100`；也支持 `root@IP:2222`、`ssh://root@IP:2222`，或只填服务器 IP / 主机名（此时端口为 22、用户为 `root`；云平台端口通常不是 22，需一并填写端口）。
   - **密码** 或 **私钥**：二选一。密码不会被保存。
   - **远端 Python**：已装好 PyTorch 的解释器，默认 `python`；使用 conda 环境时填完整路径，如 `/root/miniconda3/envs/xxx/bin/python`。
   - **远端目录**：任务目录的上级，默认 `~/fenosuite_train`；AutoDL/SeetaCloud 系统盘较小，建议填数据盘如 `/root/autodl-tmp/fenosuite`。
   - **自动安装缺少的依赖**：勾选后用远端 pip 安装缺少的训练依赖（PyTorch 除外，需与服务器 CUDA 匹配，请预先装好）。
2. 点击「测试连接」，日志中会显示远端 Python / PyTorch 版本与 GPU 型号。
3. 选择配置文件、数据来源（留空使用当前数据集）、保存目录，可选继续训练权重。
4. 点击「开始训练」。流程为：检查环境 → 上传训练代码（约 30 个源码文件）与数据 zip → 远端后台训练并实时显示日志 → 下载 `best_model.pth`、训练曲线等到保存目录。

说明：

- 每次训练在远端目录下新建 `jobs/<时间戳>/`，其中保留 `train.log` 与 `output/`；上传的数据在训练结束后自动删除。
- 训练以后台进程运行，本机断网或关闭软件不会中断训练，产物仍可在上述 `output/` 中找到。
- 点击「停止」会终止远端训练进程。

### 4.5 操作步骤（HTTP 服务）

1. 在**远程机器**上安装依赖并运行 `python run_server.py`（见第 7 节），确认本机可访问该地址（如 `http://<IP>:8765`）。
2. 在 GUI 中选择「HTTP 服务」，在「服务地址」中填写上述地址。
3. **必须**选择「数据目录」：本地会将该目录打包为 zip 上传。
4. 选择配置文件（可先「预览 YAML」确认）。
5. 点击「开始训练」；会先显示「正在打包数据目录…」「打包完成，提交任务…」，然后显示「任务已提交: <job_id>」，并每 2 秒轮询一次远程日志，在下方文本框显示。

任务结束后（成功或失败），轮询停止；若失败，会弹窗显示错误信息。

## 5. 图像分割

### 5.1 界面与路径

- **配置文件**：用于解析模型结构和预测参数（如阈值、patch_size）；可与训练时使用的 YAML 相同。可「浏览...」选择，可「预览 YAML」编辑保存。
- **权重文件**：`.pth` 或 `.pt` 文件，如训练得到的 `best_model.pth`。
- **图像目录**：待分割的图片所在目录（会递归或按实现遍历该目录下支持的图像）。
- **输出目录**：分割结果写入 **输出目录/masks/**，文件名与输入图像对应（通常为 `xxx_mask.png` 或同名 + 后缀）。

勾选「仅使用 CPU（不占用 GPU）」时，预测使用 CPU。

### 5.2 批量分割

1. 填写或选择：配置文件、权重文件、图像目录、输出目录。
2. 点击「开始分割」；下方日志框输出进度。完成后显示成功张数与失败列表（若有）。

### 5.3 单张预览

用于在批量分割前检查单张效果。

1. 在「预览图像」输入框填写路径，或点击「浏览...」选择一张图。
2. 确保配置文件与权重文件已填且有效。
3. 点击「运行预览」；左侧预览区会显示原图与 mask 叠加结果。
4. **Mask 透明度**：滑动条调节叠加透明度。
5. **显示 Mask**：勾选/取消可显示或隐藏 mask 叠加。
6. **← / → 键**：在同一文件夹内切换上一张/下一张图像并自动重新运行预览。

预览区支持**滚轮缩放**、**中键拖拽**平移画布。

## 6. 根系表型

独立的新页「根系表型beta」提供方向场辅助矢量解析、主侧根父子关系和交汇校正，操作见 [根系表型beta 使用说明](root-beta.md)。本节继续说明原有根系表型页。

### 6.1 流程概述

1. **选择掩码图像**：通过「选择文件...」或右侧工作目录树选择一张掩码图（.png、.jpg、.jpeg、.tif、.tiff）。
2. **预处理**：点击「预处理」；软件会加载掩码、做形态学与连通域等预处理，并在画布上显示预处理结果，等待用户点选根。
3. **点选根**：在画布上**点击**根所在位置（可多次点击、选择多条根）；每次点选后会重新分析，并更新骨架、主根/侧根、统计结果。
4. **撤销**：点击「撤销上次点选」或 **Ctrl+Z**，撤销最近一次点选的根。
5. **校正主根**（可选）：若自动主根轨迹不理想，点击「校正主根」，在画布上**拖拽描绘**主根轨迹，释放鼠标后按新轨迹重新分级。
6. **导出**：分析完成后可「导出 CSV...」「导出 Excel...」「导出可视化图...」。

### 6.2 输入与显示

- **掩码图像**：二值或灰度掩码，前景表示根系区域。若同目录存在同名原图（如 `xxx.png` 与 `xxx_mask.png`），画布会尽量叠加原图作为底图。
- **显示选项**（左侧「显示」分组）：可勾选/取消「显示骨架」「显示交点」「显示根尖」「显示主根」「显示二级根」，用于控制画布上叠加元素的显示。

### 6.3 参数说明（左侧面板）

- **预处理**：形态学核大小、最小连通域面积、是否开运算等。
- **断根连接**：启用后尝试将断裂的根在几何与角度约束下连接；可调最大搜索、角度容差、最小/最大间隙。
- **拓扑**：分叉点最少邻域数等。
- **边权权重**：长度、直径、曲率在边权中的权重，影响主根/侧根判定。
- **统计与清洗**：短根长度阈值、细根直径阈值、是否 Z-score 标准化等。

点击「恢复默认」可恢复为 `plant_phenotype/root_phenotype/config.py` 中的默认值。

### 6.4 导出

- **导出 CSV**：将当前分析的汇总表导出为 CSV（UTF-8 BOM）。
- **导出 Excel**：将汇总表与明细表写入同一 xlsx（sheet「汇总」「明细」），需已安装 `pandas` 与 `openpyxl`。
- **导出可视化图**：将当前画布上的骨架、主根/侧根、交点/根尖等绘制为 PNG。

### 6.5 切换图像

- 画布支持 **← / →** 键在同一目录内切换上一张/下一张掩码图；切换后需重新点击「预处理」再点选根。

## 7. 远程训练服务

### 7.1 用途

在具备 GPU 的机器上运行服务，接受 GUI 提交的训练任务（配置 + 数据包），在服务端执行训练并返回日志；本机无需 GPU 即可发起训练。

> 能 SSH 登录的服务器（如云 GPU 实例）优先使用第 4.4 节的 **SSH 远程**：无需部署代码、无需常驻服务或开放端口。HTTP 服务适合无法 SSH、或多人共用一个常驻训练服务的场景。

### 7.2 启动服务

在**仓库根目录**执行：

```bash
python run_server.py
```

默认监听 `http://0.0.0.0:8765`。可指定主机与端口：

```bash
python run_server.py --host 0.0.0.0 --port 8765
```

确保防火墙放行 8765 端口；本机 GUI 在「模型训练」→ HTTP 服务中填写 `http://<服务端IP>:8765` 即可。

### 7.3 服务端最小部署

无需拷贝整个项目。在本机仓库根目录导出最小服务包（只含 `run_server.py`、Flask 应用及训练所需的源码）：

```bash
python -m plant_phenotype.training.bundle --server -o fenosuite_server.zip
```

把 zip 上传到服务器并解压，在解压目录中安装依赖、执行 `python run_server.py`。服务器只启动训练服务，不会导入 GUI 页面。

依赖：在部署根目录执行 `pip install -r requirements-server.txt`（根目录提供，不含 PyQt6 等）；若使用 DINOv3，再执行 `pip install -r requirements-dinov3.txt`。

### 7.4 API 简要说明

- **GET /**：返回服务说明（JSON）。
- **POST /job**：提交任务。请求为 multipart/form-data：`config`（YAML 文件或内容）、可选 `data_zip`（数据目录打包的 zip）。返回 `{"job_id": "..."}`。
- **GET /job/<job_id>**：查询任务状态与日志末尾，返回 `status`、`log_tail`、`error` 等。
- **GET /job/<job_id>/artifacts**：列出该任务产物文件列表。
- **GET /job/<job_id>/download/<filename>**：下载指定产物文件（如 `best_model.pth`）。

GUI 使用 POST /job 提交、GET /job/<job_id> 轮询日志；产物下载可在后续通过脚本或浏览器调用上述接口。

## 8. 配置与数据约定

### 8.1 训练/分割 YAML（resources/configs/unet.yaml）

- **data**：`root_dir` 由界面「数据目录」或命令行传入；YAML 中可配置 `images_dir`、`masks_dir`、`mask_suffix`、`train_val_split`、`image_ext`、`mask_ext` 等。
- **train**：`epochs`、`batch_size`、`lr`、`save_dir`、`patch_size`、`lr_schedule`、`early_stop_patience` 等；`save_dir` 可被界面「保存目录」覆盖。
- **model**：`name`（如 unet、mobile_sam）、`encoder_name`、`encoder_weights`、`in_channels`、`classes` 等。ResNet50 浅层冻结用 `freeze_encoder_stages: [layer1]` 或 `[layer1, layer2]`，现成配置为 `unet_resnet50_freeze_layer1.yaml`、`unet_resnet50_freeze_layer12.yaml`。MobileSAM 用 `mobile_sam.yaml`（源码在 `plant_phenotype/vendor/mobile_sam`），在 `model.checkpoint` 填写官方 `mobile_sam.pt`。
- **loss**：类型（如 bce_dice）、权重等。
- **predict**：`threshold`、`remove_small_objects` 等，用于分割阶段。

图像与 mask 可同目录按命名区分（`xxx.png` 与 `xxx_mask.png`），或使用子目录 `images/`、`masks/`；训练时数据根目录以界面设置为准，无需在 YAML 中写死绝对路径。

### 8.2 标注配置（plant_phenotype/annotation/config.py）

- `DEFAULT_TILE_SIZE`：默认切块大小（如 512）。
- `DEFAULT_MIN_FOREGROUND_RATIO`：切块前景比例阈值，低于则排除。
- `IMAGE_EXTENSIONS`：支持的图像扩展名。
- `MASK_SUFFIX`：mask 文件名后缀（如 `_mask`）。

### 8.3 根系表型配置（plant_phenotype/root_phenotype/config.py）

- `PREPROCESS`：形态学核、最小连通域、是否开运算。
- `CONNECT_BROKEN_ROOTS`：断根连接开关与参数。
- `TOPOLOGY`：端点/交点邻域数。
- `EDGE_WEIGHT`：长度、直径、曲率权重。
- `STATS`：短根/细根阈值、Z-score 等。
- `COLORS`：主根、侧根、交点、根尖、骨架等显示颜色。

GUI 中「恢复默认」即恢复上述默认值。

## 9. 常见问题与诊断

### 9.1 无法启动或导入错误

- 确保在**仓库根目录**执行 `python run.py`，或已执行 `pip install -e .` 且从正确环境运行 `python -m plant_phenotype.main`。
- 若提示缺少 PyQt6、torch 等，请在根目录执行：`pip install -r requirements.txt`。

### 9.2 训练/分割时没有使用 GPU

- 运行诊断：`python scripts/check_cuda.py`。会显示 PyTorch 版本、是否编译 CUDA、`torch.cuda.is_available()` 及 GPU 列表。
- 若为 CPU 版 PyTorch，需卸载后重装带 CUDA 的版本，例如（CUDA 12.1）：
  ```bash
  pip uninstall torch torchvision -y
  pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
  ```
- 确认本机已安装 NVIDIA 驱动（`nvidia-smi` 可查看）。

### 9.3 远程训练提交失败

SSH 远程：

- 「SSH 认证失败」：检查密码或私钥；先在终端用同样的 `ssh -p <端口> <用户>@<主机>` 确认能登录。
- 「未安装 PyTorch」：「远端 Python」指向的解释器没有 torch。登录服务器执行 `which python` 或 `conda env list` 找到正确的解释器路径填入。
- 「缺少训练依赖」：勾选「自动安装缺少的依赖」，或按提示在服务器上执行 pip 命令。
- 训练失败时，完整日志位于远端 `<远端目录>/jobs/<任务ID>/train.log`。

HTTP 服务：

- 确认服务端已启动 `python run_server.py`，且本机可访问服务地址（如浏览器打开 `http://<IP>:8765`）。
- 使用远程服务时**必须**选择数据目录（会打包上传）；确认数据目录路径有效且可读。
- 若报 4xx/5xx，查看返回内容中的 `error` 字段；服务端日志也可帮助排查。

### 9.4 切块/还原失败

- 切块：确认源目录下存在支持的图像格式；还原时确认所选目录内有 `meta.json`（由本软件切块生成）。

### 9.5 根系表型「点选根」无反应或报错

- 先点击「预处理」，待预处理完成后再在图上点选根；若提示「点选区域无效或为空」，可尝试调整预处理参数（如最小连通域面积）或检查掩码是否为二值/灰度且前景明显。
